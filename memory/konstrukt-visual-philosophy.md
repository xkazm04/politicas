# Konstrukt is the visual language — decided, not open

The app's art direction is **Konstrukt**: Czech functionalist information
design in Ladislav Sutnar's lineage — flat geometric glyphs, enormous
numerals, uppercase, everything on a visible grid with mono index numbers and
"obr." captions. It won a 3-variant landing prototype round on 2026-07-22 over
**Broadsheet** (fused into the survivors) and **Rentgen** (archived, not
deleted, at `features/labs/rentgen/`, mounted on `/rentgen`, noindex — a living
reference for investigative sub-surfaces where fixed hexes are allowed).

Tokens live in `app/globals.css`; the page grammar (brand bar → poster title
band → numbered `border-t-4` sections → tile grids → list rows) is codified in
`docs/DESIGN.md` §5. New pillar surfaces get designed through the `prototype`
skill (directional variants behind a dock → prune/fuse → consolidate).

**Why it matters:** this is a closed decision. Do not re-propose a different
visual direction or reach for Rentgen's hex art on main surfaces — that churn
was already run and settled. Match the established grammar instead.
