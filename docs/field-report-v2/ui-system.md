## 2. Deviations (violations + partials worth a fix)

- **D1 — list-entrance-stagger P5: uncapped `delay = index * step`.** `DisciplineBoard.tsx:33`, `StatTiles.tsx:34`, `Hemicycle.tsx:82-84` (r*0.09). *Severity: low-med* — most lists are short but the hemicycle/discipline boards can be long; the tail is invisible for `n*step`. **Held elsewhere:** personas puts a `Math.min(i*step, cap)` in the primitive; politicas has no primitive to hold it, so each call site must cap. Fix: `Math.min(i*0.04, 0.6)`.
- **D2 — list-entrance-stagger P7: one-shot stagger not reduced-motion-gated at some sites.** `DisciplineBoard.tsx:32-34`, `StatTiles.tsx:34` animate under `prefers-reduced-motion`; siblings (`RealDisciplineBoard.tsx:72`, `SystemModules.tsx:75`, `Hemicycle.tsx:82`) correctly gate to `delay:0`. *Severity: med (WCAG 2.3.3-adjacent).* The `enforce-reduced-motion-fallback` rule only catches **looping** animations, so one-shot staggers slip the gate by design — a coverage gap worth a lint extension.
- **D3 — focus-management P2 / anchored-popover P4: outside-click close strands focus.** `ProvenanceCapsule.tsx:60-69` closes on outside pointerdown without the focus-restore that the Esc path does (`:73-78`). *Severity: low.*
- **D4 — focus-management P5: SVG graph `<g>` nodes remove the focus ring with no replacement.** `outline:none` on focusable graph nodes, no `:focus-visible` substitute (already documented `CLAUDE.md:1177`, `docs/harness/…/followthemoney-graph.md:49`). *Severity: med* for keyboard users on `/graf`.
- **D5 — theming-and-contrast P7: the primary palette has no contrast gate.** Only the *secondary* (forensic) theme is test-guarded (`forensicLayer.test.ts`); the primary sub-AA `steel` (4.11:1) / `signal` (4.10:1) are asserted only in a `globals.css` comment. *Severity: low-med* — the AA twins exist, but nothing fails a build if someone uses `text-steel` on small body copy.
- **D6 — design-token-usage P7: color gate is a deny-list, blind to token typos.** `no-hardcoded-colors.cjs:14` bans literal colors but cannot tell `bg-paper` from `bg-papr` (the typo renders nothing, silently). *Severity: low* — an allow-list / known-token check would close it.
- **D7 — inline-busy-state: `VerificationConsole` double-submit race + app-wide missing `aria-busy`.** Rapid `1`-then-`3` both call `handleDecide` with no `writeStatus.phase` re-check (harness-documented). No `aria-busy` on any busy control repo-wide. *Severity: med (admin-only for the race).*

- **D9 — tooltip P2/P3: native `title=` on non-focusable spans.** `DisciplineBoard.tsx:72` — hover-only, unreachable by keyboard. *Severity: low.*
- **D10 — entity-visual-identity: `GraphGlyph` runtime `switch` has no `default`.** `GraphGlyph.tsx:45-64` renders nothing for an out-of-union `kind` (compile-total only; the sibling `lowScoreReasonCopy` degrades honestly with a runtime guard). *Severity: low.*
