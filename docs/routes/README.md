# Route detail files

One file per public surface. These hold the **full dated record** of what each
route derives, what it deliberately refuses to derive, and why — the material
that used to live inline in `CLAUDE.md` and had grown it to ~222 kB (loaded into
every session's context).

Rules:

- A new finding about a surface is appended **here**, not to `CLAUDE.md`.
- `CLAUDE.md`'s route table changes only when a route's one-line identity
  changes.
- Read the file for the route you are touching before you touch it.
