# benchmark-data — TEMPORARY cross-device data bundle

Public **psp.cz** open data (Czech Chamber of Deputies) exported from the local
PGlite store as portable CSVs, so DB benchmarking can continue on a **second device**
(notably the deferred **graph case #2**, which needs Kuzu — x64-only). The 365 MB
binary `.pglite` dir is deliberately **not** committed (permanent git-history bloat +
transient WAL); these CSVs are the same data in a git-friendly, engine-agnostic form
(~24 MB, largest file 15.7 MB).

**This directory is TEMPORARY.** It is committed only to shuttle public data between
devices via GitHub; once the cross-device runs are merged back, it will be deleted
and re-gitignored. Do not build features against it.

## Contents

Generated by `scripts/db-bench/export-data.ts` (see `manifest.json` for row/byte counts):

| CSV | rows | what |
| --- | ---: | --- |
| `vote_ballot.csv` | 406,000 | one MP × one roll call — OLAP / graph source |
| `vote_event.csv` | 2,030 | roll calls (titles, tallies, outcome) |
| `person.csv` | 7,045 | MP registry |
| `organ.csv` | 1,790 | chamber / clubs / committees (tree via `parent_psp_id`) |
| `mandate.csv` | 2,157 | seats (person ↔ term) |
| `membership.csv` | 42,261 | person ↔ organ, time-bounded |
| `absence.csv` | 6,425 | excused absences |
| `kg_node.csv` / `kg_edge.csv` | 1,289 / 22,560 | the derived knowledge graph (co-votes, rebels, blocs…) |
| `vote_tag.csv` | 0 | Silver-layer theme tags (re-materialize with `npm run hybrid:materialize`) |
